# Диспетчеризація теплових пунктів

МКР №2. Для запуску потрібен Node.js 22 або новіший. Сервер і клієнт запускаються у двох терміналах.

У першому терміналі:

```sh
cd backend
npm ci
npm run dev
```

У другому:

```sh
cd frontend
npm ci
npm run dev
```

Інтерфейс відкривається за адресою http://127.0.0.1:4187. API працює на порту 3008. У кожній папці є команда `npm run build`. Зібраний сервер запускається через `npm start`, клієнт — через `npm run preview`.

Початковий реєстр у `backend/data/substations.json` містить демонстраційні записи. Вузли обліку зберігаються всередині своїх ІТП, тому при видаленні запису його прилади видаляються разом із ним. Усі зміни записуються у файл сервером. Усі показники на сторінці аналітики надходять з `/api/metrics`.

Адресу API клієнт читає з `frontend/.env`. Для перегляду реєстру з чинними фільтрами можна скопіювати URL сторінки.
